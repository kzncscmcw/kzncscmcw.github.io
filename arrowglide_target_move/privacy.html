1. Data Categories We Collect

We strictly follow the data‑minimization principle. Such information is exclusively used to build your unique player profile, finish identity verification, and synchronize target‑challenge archives, unlocked decorative skins and individual gameplay preferences across multiple mobile devices. We will never fetch extra private content irrelevant to account creation.

•                      Device‑Level Technical Metadata: The Game automatically obtains advertising identifiers (IDFA for iOS, GAID for Android), public IP address, device hardware model, operating system build version, screen resolution parameters, default system language, time‑zone setting and real‑time network mode (Wi‑Fi or cellular data). These metadata assist us in adjusting target‑object display layouts for diverse hardware and solving intermittent network disconnection problems during target‑tap matches.

•                      Target‑Challenge Behavioral Metrics: We log anonymous in‑game operation traces, such as target‑hit attempt frequency, stage restart volume, target‑clearing speed, hint‑tool utilization count, special skin activation status, daily play session length, as well as interactive behaviors towards rewarded advertisements and bonus tasks. All these records are processed in aggregated anonymous form to tune puzzle difficulty curves, roll‑out fresh challenge packs and polish overall gameplay feel.

•                      Runtime Fault Diagnostic Logs: In cases where the Game suffers crashes, screen freezing, asset‑loading failures or runtime anomalies, the system will auto‑generate diagnostic logs, error codes and device performance snapshots. These logs serve merely to locate technical defects, push subsequent patch fixes and lift system stability, and do not embed any personally‑identifiable user markers.

•                      Optional Installed‑App Catalogue Permission (User Consent Mandatory): Upon first startup, the embedded advertising SDK may pop‑up a permission request for accessing your locally‑installed application list. You enjoy full authority to reject this application. Refusal will not block any core target‑shift puzzle features. Our development crew cannot view or store this catalogue data; all relevant processing work is independently completed by the corresponding ad provider under its own privacy clauses.
